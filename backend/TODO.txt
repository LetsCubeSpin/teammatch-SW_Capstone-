------------------------------------------------------------
[중요] 왜 폴더로 나누지 않았는가
------------------------------------------------------------
이 백엔드는 하나의 Python 패키지로, 파일들이 상대 import로 얽혀 있습니다.
(예: routers/matching_v2.py -> engine/, matching.py, security.py 참조)
파일을 backend1/ backend2/ 로 물리적으로 쪼개면 import 경로가 전부 깨져
앱이 실행되지 않습니다. 그래서 "폴더 이동" 대신, 아래처럼 각 파일의
담당자를 문서로 정하는 "소유권(ownership) 표"로 분담합니다.
(코드는 하나의 패키지로 함께 돌아가고, 담당만 나뉩니다.)

   app/schemas.py         # 요청/응답 모델 (양쪽 스키마가 공존)

   app/security.py            # 인증/권한 (JWT, require_professor/student)
